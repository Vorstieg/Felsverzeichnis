# Felsstudio-Screenshots

Echte Browseraufnahmen der lokalen Felsstudio-Editoren (2D Studio und Gebiets-Studio), 1440 × 1000 Pixel,
deutsche Browser-Sprache und übersetzte deutsche Oberfläche, aufgenommen am 19. November 2026.

Die Beispiele stammen aus öffentlichen Felslager-Daten:

- [Roter Ofen / Hauptsektor](https://lager.felsverzeichnis.at/api/fs/europe/austria/lower-austria/wienerwald/roter-ofen/Hauptsektor/Hauptsektor-topo.json)
- [Bischofsmütze](https://lager.felsverzeichnis.at/api/fs/europe/austria/salzburg/dachstein-gebirge/bischofsmuetze/bischofsmuetze-topo.json)

Die Daten wurden als lokale Entwürfe geöffnet. Im Normalweg wurden die bereits
im Topo beschrifteten Grade der ersten drei Seillängen auch in den Eingabefeldern
ausgewählt. Der Variantenname „Variant 1“ wurde im lokalen Beispiel zu „Variante 1“
geändert; das optionale englische Beschreibungsfeld bleibt für die deutschen
Anleitungsbilder leer. Es wurden keine Beiträge eingereicht oder veröffentlicht.
Die Bilder zeigen die tatsächliche Oberfläche; sie wurden nicht nachgezeichnet.

| Datei                    | Ansicht                                                         |
| ------------------------ | --------------------------------------------------------------- |
| `02-bischofsmuetze.png`  | Bischofsmütze, Info-Reiter und Werkzeugleiste                   |
| `03-sportklettern.png`   | Roter Ofen, Routen mit Sportkletter-Eigenschaften               |
| `04-mehrseillaengen.png` | Bischofsmütze, Normalweg mit Seillängen                         |
| `05-fixpunkte.png`       | Bischofsmütze, Fixpunkte                                        |
| `06-einreichen.png`      | Roter Ofen, Einreichen-Schaltfläche und Editorauswahl           |
| `07-gebiet.png`          | Bischofsmütze, Gebietsdaten im Gebiets-Studio                   |
| `08-geometrie.png`       | Bischofsmütze, Lage und Geometrie                               |
| `09-gpx-bearbeiten.png`  | Importierter Zustieg von der Hofpürgelhütte im GPX-Editor       |
| `10-anreise.png`         | Verzeichnis mit Haltestelle, Parkplätzen, Hütten und Topo-Wegen |

Der GPX-Import verwendet die vorhandenen Koordinaten des Pfads „Zustieg Hofpürgelhütte“ aus dem Bischofsmütze-Topo. Der importierte Weg wurde ausschließlich im lokalen Editor geöffnet und nicht eingereicht.
